# E-invoice fixtures

Unchanged copies of public test material, used to check that Seneca reads
e-invoices the way the standard defines them.

- `xrechnung/`: business cases from the KoSIT XRechnung test suite
  (release v2026-08-31, XRechnung 3.0.2), each in UBL and in CII
  (`_uncefact`). Apache License 2.0,
  https://github.com/itplr-kosit/xrechnung-testsuite
- `zugferd/`: hybrid PDFs from the ZUGFeRD corpus, Apache License 2.0,
  https://github.com/ZUGFeRD/corpus (XML-Rechnung/FX and
  ZUGFeRDv2/correct/FNFE-factur-x-examples).
